# 节奏开跳

## Identity

- **Name**: 节奏开跳
- **Version**: 0.1.0
- **Description**: 面向 Rokid AI 眼镜的全身节奏运动。左跨、右跨、起跳三个动作，配合迎面空间箭头、IMU 判定、实时帧率和局后反馈。

## Capabilities

- audio
- network
- sensors

## Runtime

`pages/index/index.ink` 为全屏页面。首次打开显示新手准备页，请玩家找空旷、防滑的位置并站起来。确认进入教程或正式曲目时，先在独立页面用 IMU 检查姿态。静止平视时采集朝向和重力基准。换歌、重玩或进入教程时用新的读数确认姿态相近后复用基准。姿态明显改变、运动期间断流或应用退到后台后重新采集。教程可跳过。火柴人示范单脚侧迈、上身随头侧倾和原地起跳。左、右各成功两次，原地跳成功一次后记录教程完成。每侧第一次成功显示 Good，并通过语音请玩家再试一次。教程进行时双击回到选曲页。左侧可切换并试听三首曲目，右侧可查看当前曲目排行榜或重练教程。转头瞄准和镜腿滑动均可切换焦点，单击或持续瞄准 3 秒确认。

`body-state.js` 用站稳时的姿态和重力确定横向轴，把加速度换算到该坐标系，短时积分估算侧移并补偿头部转动。左右跨按这次移动的方向判定，每次移动最多命中一拍。开启动作诊断后，正式曲目和教程左下角显示当次方向、回稳或侧移就绪。就绪表示动作检测已准备好接收下一次有效侧移。起跳用合加速度判断失重。正式曲目单击暂停或继续，返回键先暂停再回主菜单。结算可重玩、查榜或回到主菜单。排行榜页单击返回。控制按键不计作运动输入。

`spatial-render.js` 用同一台透视相机投影场景、贴地靶位和来袭箭头。左跨、起跳、右跨靶位排在同一条判定线上，箭头沿各自的轨道接近。下一拍显示方向和三层判定区，外层 OK、中层 Good、内层 Perfect，边界与 `game.js` 的时间窗一致。同方向时间窗重叠时，一次新动作只给最近的一拍计分。下蹲目前停用，谱面、判定和绘制遵循同一开关。

`leaderboard-client.js` 用 `api.agent.invokeAgentApi` 调灵珠工作流，按 `song_id + chart_version` 提交和读取全时段榜。身份取 `getProfile()`，本地成绩始终先保存。从主菜单进入排行榜后，滑动镜腿切换三首歌曲的榜单，单击返回。`service-config.js` 的 `agentId` 为空时排行榜离线。

`service-config.js` 中的 `motionDiagnostics` 默认关闭，同时控制研究日志、帧率计和动作调试状态。开启后记录 `imu`（加速度及配对四元数）、`posture`（约 5 Hz 的侧移估算和动作状态）、`judgement` 和 `frame-timing`。`research-log.js` 在眼镜本地保存最近三局，开发时可由 `lan-research-log.js` 分批传给局域网接收器，也可从 `pages/research/index` 手动导出。实际动作标签需独立人工标注。发布由用户在 Studio 手动更新。

原生画面用 `#000000` 作光学透明底，舞台使用单绿细线和轮廓。网页使用独立彩色渲染。
