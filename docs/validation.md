## 边界

- 本次验证不包含新的真机动作采样，不据此声称动作识别准确率、功耗或长期佩戴舒适性。
- 公开版本的 `agentId` 默认为空，不会连接原作者的排行榜；跨账号共享能力应在自己的灵珠环境按文档重新验收。
- 测试中的完美回放、谱面覆盖和分数结果是自动化夹具，不是真人识别准确率。
- 延迟相关用例只覆盖本地时间桩与绘制桩（帧率两档切换、音频起播打点、显示偏移只作用于渲染），真机上的实际音频输出延迟仍需按 `docs/latency-tuning.md` 实测。
